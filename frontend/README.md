# Frontend React

Espaço reservado à aplicação web React. Ainda não há código de produção aqui.

Antes de iniciar:

1. Revisar os fluxos e critérios em `../docs/`.
2. Fechar o contrato OpenAPI da história que será implementada.
3. Criar a interface com estados de carregamento, vazio, erro e sucesso.
4. Cobrir o comportamento com teste antes de corrigir regressões.

Não duplicar autorização do servidor como se a validação de UI fosse segurança.

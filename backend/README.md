# Backend Java / Spring Boot

Espaço reservado à API e às regras do domínio. Ainda não há código de produção aqui.

Direção inicial: Spring Web + Bean Validation + Spring Security + Spring Data JPA; migrations Flyway; API REST com OpenAPI. Versão Java e identidade institucional precisam de decisão da squad.

Toda regra de autorização é validada no backend. Disponibilidade e transições de reserva são executadas em transação e protegidas contra concorrência pelo PostgreSQL.
